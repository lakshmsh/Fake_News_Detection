🧠 Fake News Detection

A modern web application that uses machine learning and natural language processing techniques to detect whether a news article is real or fake. Built with React, TypeScript, and Tailwind CSS for a fast, interactive, and visually appealing experience.

🚀 Overview

The Fake News Detection website allows users to input a news headline or paragraph and instantly get a prediction on its authenticity. It combines a machine learning model (trained on labeled datasets) with a clean and responsive frontend interface to make misinformation detection accessible to everyone.

✨ Features

🔍 Real-time Fake News Detection using trained ML models

🧩 Interactive UI built with modern frontend tools

📊 Accurate and fast predictions powered by intelligent algorithms

💻 Fully responsive layout optimized for all devices

⚙️ Seamless integration between backend and frontend components

🛠️ Tech Stack

⚡ Vite – blazing-fast development and build tool

💎 TypeScript – static typing for better code reliability

🧠 React – dynamic and modular user interface

🎨 Tailwind CSS – responsive and modern styling

🧱 shadcn/ui – clean and accessible UI components

🧩 Getting Started

Make sure you have Node.js and npm installed before running the project.
Installation

1️⃣ Clone the repository
git clone <YOUR_GIT_URL>

2️⃣ Navigate into the project folder
cd fake-news-detection

3️⃣ Install all dependencies
npm install

4️⃣ Start the development server
npm run dev
